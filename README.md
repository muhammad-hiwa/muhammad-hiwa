### 📌 [ziman](https://github.com/muhammad-hiwa/ziman) — Kurdish text processing for AI pipelines

Kurdish has ~30 million speakers and almost no tooling. Written in Arabic script it has no
consistent encoding — Arabic and Persian keyboards lack the Kurdish letters, so writers
substitute look-alikes. `كوردي` and `کوردی` are the same word to a reader and two unrelated
token sequences to a tokeniser.

The practical cost is invisible: a corpus fragments its own vocabulary, every affected word
gets half the training signal, and retrieval quietly loses recall. Nothing crashes. Nothing
shows up in a loss curve.

`ziman` is the normalisation layer that everyone working with Kurdish text currently rewrites
from scratch. Canonical encoding, language detection that doesn't confuse Kurdish with Persian,
segmentation that handles `؟` and the zero-width non-joiner, and Sorani→Latin transliteration.
122 tests, zero dependencies.

*PyPI has a `Natural Language ::` classifier for Arabic, Persian and Turkish — and none for the
language spoken between them. Adding one is a build error. That's roughly why the package exists.*
